OsMutation

为 OpenVZ/LXC VPS 提供一键重装 Debian/CentOS/Alpine 服务

✨ 功能特性

  • 同时支持 OpenVZ 7 和 LXC 虚拟化架构。
  • 支持重装为多种主流操作系统（Debian, CentOS, Alpine）。
  • 极其轻量，针对小内存和磁盘进行了优化。

🚀 使用方法

在终端中复制并运行以下命令：

1. 标准重装脚本：

wget -qO OsMutation.sh https://raw.githubusercontent.com/LloydAsp/OsMutation/main/OsMutation.sh && chmod u+x OsMutation.sh && ./OsMutation.sh

或使用 curl：

curl -so OsMutation.sh https://raw.githubusercontent.com/LloydAsp/OsMutation/main/OsMutation.sh && chmod u+x OsMutation.sh && ./OsMutation.sh

2. 针对小磁盘 VPS（小于 1GiB）：

wget -qO OsMutation.sh https://raw.githubusercontent.com/LloydAsp/OsMutation/main/OsMutationTight.sh && chmod u+x OsMutation.sh && ./OsMutation.sh

⚠️ 注意事项（必读）

  • 数据擦除警告： 执行脚本将安装全新的系统，旧数据会被彻底抹除！请务必提前备份重要数据。
  • 虚拟化支持： 仅支持 OpenVZ 7+ 和 LXC。不支持 OpenVZ 6。
  • 不支持虚拟机： 本工具不适用于 KVM、Xen 或 VMware 等架构。

🔍 工作原理

OpenVZ 和 LXC 属于容器虚拟化技术。宿主机的内核由所有容器共享，操作系统所需的应用程序和运行库则打包在容器内部。

OsMutation 的原理是通过直接替换容器内的系统文件来实现“重装”。简单直接，唯一需要注意的是执行顺序，因为文件之间存在依赖关系。

  • OpenVZ 7 模板： 提取自 OpenVZ 7 官方 ISO 镜像。
